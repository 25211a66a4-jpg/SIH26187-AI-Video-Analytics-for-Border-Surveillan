# SIH26187 – AI Video Analytics for Border Surveillance

## 🚨 Project Overview

**BORDER-AI** is an AI-powered video surveillance system designed to enhance border security using intelligent video analytics.

The system continuously analyzes CCTV/video feeds to detect suspicious activities, identify potential security incidents, and provide real-time alerts to security personnel.

## 🎯 Objectives

- Monitor border areas using CCTV cameras
- Detect suspicious activities automatically
- Generate real-time security alerts
- Maintain incident logs
- Reduce the need for continuous manual monitoring
- Provide a centralized surveillance dashboard
- Improve response time to security incidents

## ✨ Key Features

- 📹 **Live CCTV Monitoring**
- 🤖 **AI-based Video Analysis**
- 🚨 **Real-time Incident Detection**
- 🔔 **Security Alerts**
- 📋 **Incident Logs**
- 📊 **Surveillance Dashboard**
- 🔐 **Secure Login & Authentication**
- 🗑️ **Incident Log Management**
- 📍 **Camera/Zone Monitoring**

## 🖥️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- AI / Machine Learning
- Computer Vision
- CCTV / Video Analytics

## 🏗️ System Workflow

1. CCTV cameras provide live video feeds.
2. Video data is processed by the AI system.
3. The system analyzes the video for suspicious activities.
4. Detected incidents are recorded in the incident log.
5. Security alerts are generated for important incidents.
6. Security personnel can monitor and respond through the dashboard.
